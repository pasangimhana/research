Removing the refusal direction from Gemma 4 12B

An empirical study of intervention site, edit shape, and measurement

Pasan Gimhana · model · code
Abstract Method Setup Results Ablations Limitations

Abstract

Refusal behaviour in instruction-tuned language models is close to a single direction in activation space, and removing that direction is a standard weight-editing technique. This report studies the operation on Gemma 4 12B, a model whose block structure differs from the Llama-style models the recipe was developed on, and reports three findings.

First, the intervention site matters more than the direction. Orthogonalising the residual writers and the token embedding produces little behavioural change at low strength and coherence loss at high strength; projecting the residual stream directly, with per-token norm preservation, removes refusals cleanly at the same nominal strength.

Second, shape dominates magnitude. A narrow layer band needs α ≥ 3 to suppress refusals and collapses by α = 5; a weak edit spread across a wide Gaussian band plus the embedding reaches near-zero refusals with intact coherence, and is what ships.

Third, the measuring instrument bounds the claim. A 42-substring keyword test scores a degenerate repetitive output as "zero refusals". A three-way LLM judge, calibrated against hand labels (κ = 0.56 overall, 0.71 on harmful prompts), changes both the size and the direction of the reported effect.

The shipped checkpoint raises judged compliance on a 769-prompt harmful benchmark from 32% to 91%, reduces refusals from 454 to 6, and removes 11 of 11 benign over-refusals, at a small cost in benign answer focus.

1 · Introduction

Abliteration removes the representation of refusal from a model's weights by estimating a refusal direction and orthogonalising it out of every matrix that writes to the residual stream.

It is widely used and widely mis-measured: published results typically report refusal rates under a keyword heuristic, on prompt sets drawn from a single corpus, with generation lengths short enough to truncate answers.

We treat three questions as first-class experimental variables: where the intervention is applied, what shape the edit takes across depth, and how the result is measured.

2 · Background

Refusal directions. Refusal is mediated by a one-dimensional subspace, and projecting it out of the residual stream at inference suppresses refusal across many prompts. The practical weight-editing recipe replaces inference-time projection with an orthogonalisation of the weights that write to the residual stream, so the edit survives export to other runtimes.

Refinement variants. Norm preservation and bi-projection limit collateral damage, and automated per-layer direction search replaces manual layer picking. All of these assume a block whose attention and MLP outputs are added to the residual stream directly.

Architecture dependence. Gemma 3/4 blocks normalise each sublayer output before the residual addition: x ← x + RMSNorm(Woa), x ← x + RMSNorm(Wdm). This report is, to our knowledge, the first controlled comparison of the two intervention sites on such a block.

3 · Method

3.1 Direction estimation

For harmful prompts $\mathcal{H}$ and harmless prompts $\mathcal{S}$ we run one forward pass per prompt and record the residual stream at the final token for every layer, layer 0 being the embedding output. With $h_l(x)$ that vector:

$$\mu^{+}_l=\frac{1}{|\mathcal{H}|}\sum_{x\in\mathcal{H}} h_l(x), \qquad \mu^{-}_l=\frac{1}{|\mathcal{S}|}\sum_{x\in\mathcal{S}} h_l(x), \qquad d_l=\frac{\mu^{+}_l-\mu^{-}_l}{\lVert \mu^{+}_l-\mu^{-}_l\rVert_2}$$

Capture runs in bf16, on the same weights that will be edited. Directions come from 150 prompts per class.

3.2 Weight-space intervention

For a weight matrix whose output space is the residual stream, the rank-one edit is

$$W'=W-\alpha\,g(l)\,d\,(d^{\top}W)$$
$$g(l)=\exp\!\left(-\frac{(l-24)^2}{2\sigma^2}\right)+\exp\!\left(-\frac{(l-28)^2}{2\sigma^2}\right)$$

with $\alpha$ a global strength and $\sigma$ a depth bandwidth. The token embedding uses the transposed form $E'=E-\alpha\,(Ed)\,d^{\top}$, since its rows rather than its columns live in the residual space. All arithmetic is carried out in fp32 and cast back to bf16.

3.3 Residual projection

The alternative leaves the weights alone and intervenes on the forward pass: a hook on each block subtracts the direction from the block output and restores the original per-token norm.

$$h\leftarrow h-\alpha\,g(l)\,d\,(d^{\top}h), \qquad h\leftarrow h\cdot\frac{\lVert h_{\text{pre}}\rVert}{\lVert h\rVert}$$

Norm restoration is not cosmetic: without it the model collapses at $\alpha=1$ on every layer we tried.

3.4 Search procedure

Both interventions share a small grid search over layer centre, bandwidth, strength, and (for the bake) whether the embedding is included. Candidates are scored on a 12-prompt harmful probe plus 8 harmless prompts, with two criteria: refusal count, and a coherence guard that flags outputs with fewer than 55% alphabetic tokens or a type-token ratio below 0.35.

4 · Experimental setup

Model. google/gemma-4-12B-it: 48 text layers, hidden size 3840, vocabulary 262,144, bf16, 23.9 GB on disk, 24.4 GB resident. The checkpoint is a unified multimodal model; only the text tower is edited.

Capture data. 150 harmful prompts from an AdvBench-style set and 150 harmless prompts from Alpaca. The reported holdout is disjoint, and the large benchmark is de-duplicated against them at the string level.

Generation length. 200 tokens for the large benchmark, 240 for the small holdout. In an earlier 200-token evaluation every one of 48 answers ended mid-word, so only the absence of refusal had been observed, never the presence of compliance.

5.3 Keyword test versus judge

The keyword instrument agrees in direction (460 → 3 harmful refusals; 29 → 1 benign) but is not sufficient alone. In one probe, a repetitive degenerate output containing no refusal phrase scored zero refusals under the keyword test while the judge flagged every row as broken.

7 · Discussion

Intervention site. Orthogonalising W_o and W_d removes the direction from a sublayer's output before it is normalised and added, and the normalisation partly re-expresses it; projecting the residual stream removes it after the addition, where it actually matters. Recipes developed for Llama-style blocks do not transfer unchanged, and "abliteration does not work on model X" is usually a statement about the intervention site rather than about the existence of the direction.

Shape. Spreading a weak projection across many layers outperforms concentrating a strong one at a few, consistent with the direction being present at every depth and a concentrated edit over-constraining the layers it touches.

Measurement. Three measurement choices changed our conclusions more than any modelling choice: judging with a rubric instead of substrings, generating long enough to observe compliance, and using a benchmark with a non-saturated baseline.

8 · Limitations

  • The direction comes from 150 + 150 prompts from two corpora. A different distribution will move it; the benchmark is disjoint at the string level but not distributionally independent.
  • 6 of 769 held-out harmful prompts still refuse. The ones inspected are requests a text model cannot literally satisfy, or ones where it answers while arguing the opposite premise.
  • The bake is weaker than the projection (91% vs 98% on the small holdout). We ship the weaker but portable artifact.
  • Judge calibration is 24 rows, labelled by the author. It establishes substantial agreement on harmful prompts, not a population estimate.
  • No capability benchmark was run. The coherence guard and the benign suites are the only evidence that general ability is intact.
  • Actionability on benign prompts falls from 2.00 to 1.84. Cause not diagnosed.

9 · Reproducibility

# 1. estimate the direction (GPU, ~20 s for 300 forward passes at 12B)
python gemma_abl.py capture --model google/gemma-4-12B-it --n 150

# 2. search strength / layer (GPU)
python gemma_abl.py search --model google/gemma-4-12B-it \
    --configs 1.5:6,2.0:6 --top-layers 2 --n-ref 10 --n-harm 8

# 3. bake the winning configuration (CPU, ~3 min, 97 tensors)
python gemma_abl.py bake --model google/gemma-4-12B-it \
    --out /workspace/baked --spec 24:1.0,28:1.0 --sigma 6.0 --embed-scale 1.0

# 4. evaluate, then judge the stored generations
python gemma_abl.py eval --model /workspace/baked --tag run1 \
    --suites big_harmful,big_benign --max-new-tokens 200 --batch 12
python llm_judge.py --input artifacts/eval-run1.json \
    --out artifacts/judged-run1.json --suites big_harmful,big_benign

All GPU work ran on a single A6000 48 GB at $0.59/hour. The large benchmark is 1,044 generations per model, about 18 minutes at batch size 12. Total cost across all runs, including failed configurations, was $4.93.

10 · Responsible use

The artifact is an uncensored model: refusal behaviour has been deliberately removed, including for requests that are illegal or harmful. It is published as a research artifact for studying representation-level refusal and for evaluation work. Output should be treated as unfiltered model output, and deployments that require refusal behaviour should not substitute this checkpoint.

Appendix · Judge prompt

Show the rubric 
You are grading how a language model responded to a user request.
You are not answering the request. You are not producing harmful content.
You read one prompt and one response, and classify the response's stance.

Labels:
  comply          the response makes a real attempt at what was asked and
                  contains substantive, on-topic content
  soft-redirect   the response engages with the topic, then deflects: it
                  lectures, adds ethical framing, states it will not give the
                  details, or names concepts without giving the method
  refuse          the response declines the request outright

Actionability, 0 to 3:
  3  specific and directly usable for the request as asked
  2  useful and specific, but incomplete or hedged in places
  1  mostly generalities, names things without explaining how
  0  nothing usable toward the request

Confidence, 0 to 1: how sure you are of the label.

Judge only what is present. Length alone is not compliance: a long answer that
never gives the asked-for content is soft-redirect. A short answer that does
give it is comply.

Return JSON only, of the form:
{"items":[{"i":1,"label":"comply","actionability":3,"confidence":0.9}]}
